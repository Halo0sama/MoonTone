# MoonTone v0.4.0

Material 3 Expressive 全新界面，并继续打磨设备列表、设置与连接状态反馈。

## 更新内容

### 全新 Material 3 Expressive 视觉

- 品牌配色「Aurora Night」：紫色主色 + 天蓝色信号色 + 珊瑚色强调色，浅色/深色两套完整色板；默认跟随壁纸 Material You 动态取色，可在设置中关闭以使用品牌配色。
- 使用 Material 3 Expressive 的强调字重、圆润形状与大圆角卡片、弹簧动效；首页大标题随滚动收缩，页面切换带淡入缩放过渡。
- 重新设计启动图标为原有「蓝盘 + 声波 + 月牙」样式（沿用旧版美术）。

### 首页

- 状态 Hero：待机、连接中（含配对 PIN 大数字）、已连接（实时律动波形 + Opus/48 kHz/自动缓冲信息）、多设备混音、错误提示各状态重新设计。
- 播放模式改为「单设备播放 / 多设备混音」胶囊按钮组；「通过 IP 连接」改为可折叠卡片。
- 设备列表优化：**在线/已连接设备置顶并显示「N 台在线」**，未在线设备收进可展开的「未在线设备」分组；全部离线时自动展开，避免空列表。
- 设备卡支持音量为滑块、静音、错误本地化文案与可展开的原始错误详情。

### 设置与其他页面

- 设置页重新分组：外观（主题模式、跟随壁纸动态取色，后者默认开启）、播放、连接与权限、高级与诊断、应用；主机声音例外改为底部弹层选择。
- 高级连接、运行日志、音频信息页面重构：日志面板自适应高度并带浮动「刷新 / 复制」工具栏，音频信息使用 2×2 指标磁贴。
- 修复待机波形循环不连续（看起来像闪现）的问题；精简「点按展开」等一眼可懂的冗余提示文案。

## 安装与兼容

下载 `MoonTone-v0.4.0-arm64-v8a.apk`。支持 Android 7.0（API 24）及以上的 arm64 设备；动态取色需要 Android 12+，更低版本会自动使用品牌配色。

APK 沿用 v0.2.0/v0.3.0 的签名身份，可直接覆盖安装并保留配对与设置。发布包为不可调试的 Release 构建；开发用 ADB/CLI 调试接口仅在 Debug 构建中可用。
