# MoonTone v0.3.0

集中整理设置入口，并改善连接生命周期、音频缓冲和 Android 17 权限处理。

## 更新内容

- 新增独立设置页：主机声音、麦克风上行、权限、音频信息、日志、证书导出、高级连接和更新检查集中管理。首页保留设备与播放操作，单设备播放和多设备混音通过标签切换。
- 主机同时播放声音支持全局默认和设备例外，保留旧版已保存的设备选择，下次连接或重连生效。
- 单路与混音共用自适应缓冲；网络抖动时增加保护，稳定后逐渐消退积压，避免仅降低目标而延迟长期不回落。
- 修复取消连接、重连、快速切换及界面重建中的旧回调和资源释放问题；修复立体声漂移、混音短写及静音音量恢复。
- 完善 Android 17 局域网权限、后台播放与麦克风前台服务；配对固定服务端证书，日志和系统备份排除会话秘密及私钥。
- 修复 PC 麦克风接收器的乱序、重复包、序号跳变和内存增长问题。

## 安装与兼容

下载 `MoonTone-v0.3.0-arm64-v8a.apk`。支持 Android 7.0（API 24）及以上的 arm64 设备。Android 17 首次连接需要允许局域网访问，麦克风权限仅在开启上行时申请。

APK 沿用 v0.2.0 的签名，可直接覆盖安装并保留配对与设置。本次使用不可调试的 Release 构建；开发用 ADB/CLI 调试接口仅在 Debug 构建中可用。

主机声音修改在下一次连接或重连生效。蓝牙输出仍受耳机和系统缓冲影响；本次没有完成真实校园网与蓝牙耳机的端到端声学延迟或多小时稳定性测量，不能保证所有网络条件下零卡顿。
