# 设置页与首页整理

2026-10-18。按用户反馈，将分散的选项统一收进独立设置页，移除首页重复出现的主机声音开关。

## 页面与功能归属

首页右上角只有一个设置入口，在连接前、连接中和播放中均可进入。首页保留设备发现、保存/移除、配对 PIN、连接/断开、手机静音和混音音量。单设备播放和多设备混音通过两个标签页展示，不再同时堆叠两份设备列表。

| 设置分组 | 内容 |
| --- | --- |
| 播放 | 主机同时播放声音默认值、设备声音例外、麦克风上行、音频信息 |
| 连接与权限 | 局域网访问、播放通知、系统应用设置 |
| 高级与诊断 | 手动 RTSP 连接、运行日志、导出公钥证书 |
| 应用 | 启动时检查更新、手动检查更新、版本信息 |

“设备声音例外”“高级连接”“运行日志”“音频信息”使用独立子页面，返回键先回设置，再回首页。进入设置或切换标签不会执行断开；停止播放仍需明确点击断开/停止按钮。两个播放管线保持原有用途，不将切换显示标签当作切换串流。

麦克风上行仍针对单设备连接的当前电脑，移动入口后不改变其前台服务生命周期。高级连接只接入外部已启动的会话，不再作为首页“更多”里影响普通连接的隐藏模式。手动会话密钥只留在页面内存，离开页面后清除，不写入 SharedPreferences 或保存的页面状态。

## 设置兼容与生效时机

全局偏好保存在 `moontone_settings`；旧的 `moontone_host_audio` 主机地址键保持不动。有效的主机声音设置按以下优先级读取：

1. 该主机已有的显式布尔值，包括上一版 APK 保存的值。
2. 新增的全局默认，初始仍为关闭，保持旧行为。

在设备例外页面选择“跟随默认”会移除该主机的显式值。这样既能统一设置，也保留用户之前对个别电脑的选择。主机声音在下一次连接/重连时生效；麦克风开关是即时操作；启动更新检查开关在下次启动时生效。日志、导出、手动更新检查均由用户点击触发。

## 代码入口

- `ui/MainActivity.kt`：权限与生命周期、更新检查。
- `ui/MoonToneScreen.kt`：稳定挂载的控制器观察、发现、配对、导航和首页。
- `ui/SettingsScreen.kt`：设置分组、偏好监听、设备例外。
- `ui/AdvancedScreens.kt`：手动连接输入校验、日志与音频信息。
- `data/AppPreferences.kt` / `HostAudioPreferences.kt`：全局偏好与旧格式兼容。

设置导航不销毁应用级单路/多路控制器，配置重建保留页面与非敏感输入。敏感会话密钥不保存。输出信息按系统检测结果显示，不把“设备可用”当作“该设备正在播放”；缓冲参数也不当作端到端测量。
